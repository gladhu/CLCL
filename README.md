# CLCL

CLCL 是 Windows 上的剪贴板历史工具。复制过的文字、图片和文件会留在历史里，用热键或托盘图标叫出来，选中后即可粘贴回正在使用的窗口。常用内容可以存成模板。

当前版本：**2.2.2**。适用于 Windows 7 及更高版本。

## 功能

- 记录剪贴板历史，支持文本、图片、文件等多种格式
- 把常用内容按目录注册成模板，并可单独设置热键
- 用热键或托盘图标弹出菜单，选中后自动粘贴
- 菜单里显示图片缩略图和工具提示
- 在查看器中浏览、编辑历史和模板
- 按窗口设置要忽略的程序，以及各自的复制、粘贴键
- 退出时保存历史，下次启动继续使用
- 可用插件扩展处理方式
- 搜索历史和模板
- 在 Alt + C 弹出的历史列表顶部直接输入文字过滤

## 怎么用

启动后，任务栏通知区域会出现回形针图标。

| 操作 | 结果 |
| --- | --- |
| 左键点击托盘图标，或按 Alt + C | 弹出历史菜单 |
| 在弹出菜单顶部的搜索框输入文字 | 只显示匹配的历史 |
| 在菜单中选择一项 | 放入剪贴板，并粘贴到当前窗口 |
| 选择时按住 Shift | 只放入剪贴板，不粘贴 |
| 按 Esc，或点击菜单外面 | 关闭菜单 |
| 右键点击托盘图标 | 打开查看器 |
| 查看器中按 Ctrl + F，或按 Alt + F | 打开搜索窗口 |
| 命令行 `CLCL.exe /s` | 打开搜索窗口 |

弹出菜单里不输入文字时，仍是原来的完整菜单，模板、查看器、取消等项目留在列表底部。没有匹配的历史时，会显示“没有匹配的项目”。

搜索窗口在不输入关键字时列出最近的历史。输入关键字后，会同时查找历史和模板的标题、来源窗口以及文本内容。

## 安装

运行发布包中的安装程序即可。卸载请使用系统的“应用和功能”，卸载前先退出 CLCL。

历史和设置默认保存在：

`C:\Users\<用户名>\AppData\Local\CLCL`

若希望数据跟程序放在一起，在 `clcl_app.ini` 中写入下面的内容后再启动：

```ini
[GENERAL]
portable=1
```
